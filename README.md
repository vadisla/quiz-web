# Music Quiz Live 🎵

Интерактивная веб-платформа для проведения музыкальных квизов в реальном времени.

- **API сервер (Бэкенд на Railway):** [https://backend-production-4042.up.railway.app](https://backend-production-4042.up.railway.app)
- **Исходный код (GitHub):** [https://github.com/vadisla/quiz-web](https://github.com/vadisla/quiz-web)

---

## 🏗 Архитектура системы

1. **Генератор квизов (`/Users/vadisla/projects/quiz`):**
   - Консольная утилита на Mac для быстрого создания новых игр из списка исполнителей.
   - Подбор треков через Spotify API и Яндекс.Музыку по уровню сложности.
   - Загрузка аудио с защитой от блокировок через официальный Deezer Preview API.
   - Нарезка 20-секундных отрывков с 1с фейдами через `ffmpeg`.
   - Нормализация громкости всех треков по стандарту EBU R128 (`normalize_loudness.py`).
   - Поиск и smart-кадрирование фото артистов (800x600 с детекцией лиц).
   - Автоматическая синхронизация созданной игры в папку `quiz_web/backend/games/`.

2. **Бэкенд (`/backend` — Хостинг Railway):**
   - Легковесный сервис на Python + FastAPI.
   - HTTP Range стриминг аудио (`206 Partial Content`) для мгновенного старта и плавной перемотки.
   - Раздача метаданных игр и фото артистов.

3. **Фронтенд (`/frontend` — Хостинг Vercel):**
   - Интерактивное веб-табло на чистом Vanilla JS / CSS.
   - Лобби со списком доступных квизов.
   - Экран раунда: анимированный виниловый диск, 20-секундный таймер, сетка треков.
   - Карточка ответа: открытие правильного артиста и названия песни, демонстрация фото.
